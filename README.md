# Sindh Local Government Act 2013
### سندھ لوکل گورنمنٹ ایکٹ 2013 | سنڌ لوڪل گورنمينٽ ايڪٽ 2013

## Official Digital Legal Reference Portal

A comprehensive, free, trilingual (English / Urdu / Sindhi) public legal reference project for the **Sindh Local Government Act, 2013** — built section-by-section from the official Sindh High Court compiled text (Judges' Library, Karachi).

🌐 **Live website:** https://raheemsariouae-786.github.io/Sindh-Local-Government-Act-2013/

This project is designed for:
- Councillors, Chairmen, Vice Chairmen, Mayors, Deputy Mayors
- Lawyers & Judges
- Government Officers
- Researchers & Students
- Journalists
- Citizens
