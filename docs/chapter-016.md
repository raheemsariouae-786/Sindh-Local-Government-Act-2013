# Chapter XVI — Miscellaneous

سندھ لوکل گورنمنٹ ایکٹ 2013 کا سولہواں باب متفرق مگر اہم دفعات پر مشتمل ہے — قواعد و ضابطے، اختیارات کی تفویض، مشترکہ کمیٹیاں، اپیلیں، تجاوزات، زمین کا حصول، مفادات کا تصادم، مقدمہ دائر کرنے کا طریقہ، نوٹس، سرکاری دستاویزات، سرکاری ملازم کی حیثیت، حسنِ نیت کا تحفظ، اور معلومات تک رسائی کا حق۔
