# Sindh Local Government Act, 2013

## Welcome | خوش آمدید | ڀلي ڪري آيا

This is the official documentation index for the **Sindh Local Government Act, 2013** Project — a free, trilingual (English / Urdu / Sindhi), section-by-section legal reference for Councillors, Chairmen, Mayors, lawyers, judges, officers, researchers, students, journalists and citizens.

یہ سندھ لوکل گورنمنٹ ایکٹ 2013 پراجیکٹ کی سرکاری دستاویزی فہرست ہے — کونسلرز، چیئرمینوں، میئرز، وکلاء، ججز، افسران، محققین، طلباء، صحافیوں اور شہریوں کے لیے ایک مفت، تین زبانوں (انگریزی/اردو/سندھی) پر مبنی مکمل قانونی حوالہ۔

Source: Sindh High Court compiled text (Judges' Library, Karachi). See [ACT-STRUCTURE.md](ACT-STRUCTURE.md) and [LEGAL-DOCUMENTATION-STANDARD.md](LEGAL-DOCUMENTATION-STANDARD.md) for how this project verifies content.
